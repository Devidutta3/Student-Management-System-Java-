# Student Management System (Java)

A beginner-friendly **Java console-based project** to manage student records using core Java and OOP concepts.

---

## 🚀 Features
- Add new student
- Display all students
- Update student marks using ID
- Menu-driven console interface

---

## 🛠️ Technologies Used
- Java
- OOP Concepts
